# Terror Prints Studio — licenses

The delivery includes dist/licenses/ from the actual build. Retain those license and notice files when redistributing the application. The package script rejects a missing or empty license directory; this presence check is not a legal opinion about rights.

Three.js and manifold-3d are runtime dependencies named by the implementation contract. Bundled text/glyph data must retain its actual upstream font notice as supplied by the build owner. esbuild is a build tool; it is not installed on the static host. The build owner remains responsible for the dependency and font provenance, versions and applicable notices.

The sage/cream paw icons are original local vector artwork for this project, rasterized locally with Sharp. They contain no purchased stock assets or copied third-party logo.

Imported STL files and catalog entries are supplied by the person using the browser. Importing a model does not grant rights to it. Keep the creator's permitted-use terms with any redistributed models.
